# Hi, I’m Soham Kumawat

I build for the browser and the workbench. I built an Arduino walking stick that turns distance readings into sound. I also write about how browsers could establish trust on the web.

## Selected projects

| Project | What you can explore |
| --- | --- |
| [VisionX](https://github.com/sohamorbit/VisionX) | An offline walking-stick prototype that combines ultrasonic and infrared sensing with audible alerts. The repository includes firmware, wiring diagrams and bench photos. Winner at the IoT Workshop, Techno NJR, Udaipur. |
| [Voloweb Secure Protocol](https://github.com/sohamorbit/VSP) | A research proposal exploring how the web could authenticate identities without traditional certificate authorities. The technical specification lays out the proposed architecture. |

## Tools I use

JavaScript and Express for web services, Python for data APIs, and C++ on the Arduino Uno for sensors and embedded controls.
